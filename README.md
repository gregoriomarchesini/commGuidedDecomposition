## Introduction to Signal Temporal Logic (STL)

Signal Temporal Logic (STL) is a formal language used for specifying temporal requirements in cyber-physical systems and multi-agent systems. STL allows you to express complex temporal properties over continuous signals, making it a powerful tool for system verification and synthesis.

## Repository Overview

This repository consists of three main modules:

### Module 1: Task Description
- **Description:** Module 1 focuses on defining and representing the task specification for the multi-agent system. It allows users to specify temporal logic constraints on the desired behavior of the agents.
- **Implementation:** The code in this module provides functions and tools for creating, parsing, and manipulating STL formulas representing the task.

### Module 2: Communication Graph
- **Description:** Module 2 is responsible for handling the communication graph among agents. The communication graph defines how agents in the system can exchange information and coordinate their actions.
- **Implementation:** The code in this module provides functionalities for constructing, visualizing, and analyzing the communication graph.

### Module 3: Decomposition Algorithm
- **Description:** Module 3 contains the core decomposition algorithm. It takes the task specification and communication graph as inputs and decomposes the STL specifications among the agents, allowing them to work together to satisfy the overall task requirements.
- **Implementation:** This module implements the decomposition algorithm and provides APIs for interacting with it.
